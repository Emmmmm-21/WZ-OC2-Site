📖 使用说明

  1. 随机选图：点击「抽取」按钮，按 Web Crypto 强随机从全部地图中抽一张（5 轮内不重复）并展示地图图/菜单图；网页版左右分栏、手机端上下排列，点击图片可放大。
  2. 首页：上方为地图下载入口（三按钮）；下方按钮直达对应作者地图清单；底部为各作者地图数柱状图（Chart.js）。
  3. 地图菜单速查：左侧选择作者，右侧卡片网格展示地图。点击卡片弹出大图弹窗：
    • 关闭：右上角 × 或 Esc（点击空白不关闭）。
    • 切换「地图图 / 菜单图」：用弹窗顶部 tab。
    • 切换上一张 / 下一张：用弹窗左右按钮，或键盘 ← / →，按钮下方显示地图名。
    • 弹窗中的图片点击后占满全屏：滚轮上下滚动缩放，鼠标拖动平移位置。
    • 地图名重命名请到「更新（受密码保护）→ 地图更新 → 改名」操作。
  4. 厨房文件下载：含「地图文件下载」与「mod下载」两个标签。地图文件下载为全部地图打包 levels.zip（三选一下载），下方显示近 5 条更新日志；mod下载为 BepInEx 框架置顶（框架 → 全部 Mod 打包 → 13 款 Mod 列表），每项各带三个下载按钮（腾讯云 / GitHub / 百度网盘）。
  5. 更新（密码）：密码 Xqk20020731。解锁后含三个子界面：地图更新、地图文件下载（配置 levels.zip 三链接并写日志）、Mod 下载（增删改 Mod 三链接），数据存 localStorage。
  6. 导出与备份：左卡「图片导出」（地图图与菜单图 zip）；右卡「数据备份与恢复」内部两栏——全量操作（导出 / 导入 JSON）与危险操作（重置为示例数据 / 清空自定义数据，不可撤销请先备份）。
  7. 设置：更新日志、使用说明、关于。

注意事项

  • 单文件 HTML 通过 file:// 协议双击打开即可使用；所有图片已内嵌进本文件（base64），无需配套素材文件夹。
  • 所有数据（替换图 base64、链接）保存在浏览器 localStorage，清除浏览器数据会丢失自定义内容，建议定期导出 JSON 备份。
  • Edge / Chrome / 搜狗浏览器均已适配。建议分辨率 ≥ 1280×800。
  • 密码区分大小写，请勿泄露。
